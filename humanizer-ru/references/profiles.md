# Profiles — контекстная настройка строгости

Передай необязательный контекст-хинт для настройки строгости. Если не указан — авто-определение по сигналам (короткий + хэштеги = telegram, код = tech-blog, обращение = письмо, иначе = blog).

---

## Определения профилей

**`telegram`** — короткий формат, допустимы фрагменты, разговорный тон, один-два эмодзи в конце строки ОК.
**`blog`** — стандарт по умолчанию. Все правила на полную силу.
**`habr`** — технический блог с кодом. Технические термины не флаговать.
**`letter`** — деловое письмо или email. Строже на промо-язык; официальный тон отчасти уместен.
**`docs`** — документация, README, инструкции. Ясность важнее голоса.
**`casual`** — Slack, личные заметки, быстрые ответы. Только P0.

## Матрица допусков

| Правило | telegram | blog | habr | letter | docs | casual |
|---|---|---|---|---|---|---|
| Пассивный залог | relaxed | strict | relaxed | relaxed | relaxed | skip |
| Канцелярит | strict | strict | relaxed | relaxed | relaxed | P0 only |
| Шаблонные вступления | strict | strict | strict | relaxed | skip | skip |
| Уровень 1 словарь | strict | strict | **partial** | strict | relaxed | P0 only |
| Промо-язык | relaxed | strict | strict | **extra strict** | strict | skip |
| Инфляция значимости | strict | strict | strict | **extra strict** | relaxed | skip |
| Равномерность абзацев | skip | strict | strict | strict | relaxed | skip |
| Переходные фразы | skip | strict | strict | strict | relaxed | skip |
| Раздутые выводы | skip | strict | strict | **extra strict** | skip | skip |
| Размытые ссылки | strict | strict | strict | strict | strict | P0 only |
| False agency | strict | strict | strict | strict | relaxed | P0 only |
| Голос-наблюдатель | strict | strict | strict | strict | relaxed | skip |
| Ложные крайности | strict | strict | strict | strict | relaxed | P0 only |

**Habr-исключения (Уровень 1):** Следующие термины имеют техническое значение и не флагуются в tech-контексте: `масштабирование`, `интеграция`, `мониторинг`, `оптимизировать`, `имплементировать`, `верификация`, `фреймворк`. Всё равно флаговать: `погрузиться`, `нарратив`, `синергия`, `парадигма`, `экосистема` (метафора), `трансформация` (без конкретики).

**«Extra strict»** — флаговать даже пограничные случаи.

**«Skip»** — не аудировать эту категорию для этого профиля.

## Авто-определение контекста

| Сигнал | Определённый контекст |
|---|---|
| Меньше 300 слов + хэштеги или @упоминания | `telegram` |
| Блоки кода, технические термины, архитектура | `habr` |
| Обращение («Добрый день», «Уважаемый») | `letter` |
| Пошаговые инструкции, структура README | `docs` |
| Текст внутри `~/.claude/skills/` или mcp-конфигов | `docs` |
| Нет выраженных сигналов | `blog` |
