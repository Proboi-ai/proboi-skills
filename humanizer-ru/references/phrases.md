# Phrases — словарь AI-паттернов

Полный словарь слов и шаблонных фраз, которые надо менять или удалять. Открой когда нужна детальная замена.

---

## Канцелярит и бюрократизмы

Русский AI влюблён в официально-деловой стиль там, где он не нужен.

- **«Являться» вместо «быть»**: «данный подход является оптимальным» → «этот подход — оптимальный» / «этот подход работает лучше всего»
- **«Данный/данная/данное»**: замени на «этот/эта/это» или «вот»
- **«Осуществлять/реализовывать» вместо «делать»**: «осуществить переход» → «перейти»; «реализовать проект» → «сделать проект» / «запустить проект»
- **«Обеспечивать»** в смысле «давать»: «обеспечивает возможность» → «позволяет»; «обеспечивает рост» → «даёт рост». «Обеспечивает» оставь только когда речь о гарантии/безопасности
- **«В рамках»**: «в рамках данной статьи» → «в этой статье»; «в рамках проекта» → «в проекте»
- **«Проведение/осуществление» + отглагольное существительное**: «проведение анализа» → «анализ»; «осуществление контроля» → «контроль»
- **Цепочки родительного падежа**: «целью повышения эффективности процесса управления качеством» → переписать в живые предложения
- **«Вышеизложенное/нижеследующее»**: убрать, указать конкретно что имеется в виду

---

## Слова-маркеры уверенности (убрать)

AI использует их чтобы звучать значительнее — они добавляют слова, не добавляя смысла.

- **«Безусловно»** → убрать или «да»
- **«Несомненно»** → убрать
- **«Очевидно»** → убрать; если очевидно — не говори, просто скажи факт
- **«Безусловно важно»** → просто скажи что важно
- **«Стоит отметить»** → убрать, скажи сам факт
- **«Следует отметить, что»** → убрать
- **«Важно подчеркнуть»** → убрать
- **«Нельзя не отметить»** → убрать
- **«Необходимо учитывать, что»** → убрать или «учти:»
- **«Как было отмечено выше»** → убрать или переформулировать конкретно

## Словарь AI-паттернов

Слова разбиты на три уровня по надёжности сигнала.

- **Уровень 1 — всегда заменять.** Появляются в 5-20 раз чаще в AI-тексте, чем в человеческом.
- **Уровень 2 — флаговать в кластерах.** По отдельности допустимы, два и больше в одном абзаце — сигнал AI.
- **Уровень 3 — флаговать по плотности.** Обычные слова, которые AI просто переиспользует. Флаговать только при насыщении (~3%+ слов текста).

### Уровень 1 — всегда заменять

| Заменить | На |
|---|---|
| погрузиться / погружение | рассмотреть, разобрать, изучить |
| ландшафт (метафора) | рынок, среда, поле, область |
| нарратив | история, рассказ, точка зрения |
| экосистема (метафора) | система, сообщество, рынок, сеть |
| синергия / синергетический | (описать конкретный совместный эффект) |
| трансформация / трансформировать | изменение, перемена; «изменить», «перестроить» |
| цифровизация / цифровая трансформация | (описать конкретно что оцифровывается) |
| парадигма | модель, подход, принцип |
| комплексный / комплексно | полный, всесторонний, разносторонний — или описать что включено |
| актуальный / актуальность | важный, нужный, своевременный — или описать почему важно |
| оптимальный | лучший, подходящий, наиболее эффективный |
| инновационный / инновация | новый, передовой — или описать что нового |
| уникальный | (сказать чем конкретно отличается) |
| стратегический / стратегически | (описать реальную стратегию или убрать) |
| масштабирование / масштабировать | рост, расширение; «вырасти», «расширить» |
| бесшовный / бесшовно | плавный, без трений, без разрывов |
| функционал | функции, возможности, инструменты |

| точки соприкосновения | (описать конкретно) |
| дорожная карта (метафора) | план, список задач, расписание |

| глубокое погружение | подробный разбор, детальный анализ |
| эффективный / эффективно | работающий, результативный — или сказать как именно эффективно |
| значимый / значимость | важный — или описать конкретную значимость |
| проактивный | (описать конкретное действие вместо слова) |
| холистический | полный, целостный — или описать что включено |
| релевантный | подходящий, важный, нужный |

| Заменить | На |
|---|---|
| формировать | создавать, делать, выстраивать |
| обеспечить (в смысле «достичь») | добиться, получить, дать |
| реализовать | сделать, запустить, воплотить |
| осуществить | сделать, провести, выполнить |
| имплементировать | ввести, запустить, применить |
| интегрировать | включить, добавить, встроить |
| оптимизировать | улучшить, ускорить, упростить |
| систематизировать | упорядочить, собрать, структурировать |
| верификация / верифицировать | проверка; проверить |
| мониторинг / мониторить | слежение; следить, отслеживать |
| аналитика (как общее слово) | данные, статистика, цифры |
| консолидация | объединение; объединить |
| категоризация | разбивка по категориям; разбить |
| контекст (как затычка) | (убрать или уточнить какой контекст) |

### Уровень 3 — флаговать при высокой плотности

| Слово | Что делать |
|---|---|
| важный / важно | Часть заменить на конкретику: числа, примеры |
| существенный / существенно | Описать насколько и почему |
| значительный / значительно | То же — конкретика вместо степени |
| современный | Назвать конкретный год или период |
| передовой | Сослаться на конкретный пример или бенчмарк |
| эффективный | Описать как именно или привести метрику |
| успешный / успешно | Описать что именно говорит об успехе |
| активный | Сказать что конкретно происходит |

## Английский jargon (если просочился в русский)

Калька с английского — частый AI-сигнал на постах про бизнес/продукт. Меняй на русский эквивалент:

| Заменить | На |
|---|---|
| занавигировать (вызовы / сложности) | справиться, разобраться, пройти |
| сделать deep dive | подробно разобрать, копнуть глубже |
| lean into | принять, опереться на, идти в |
| game-changer | переворот, новая планка, прорыв |
| double down | усилить, удвоить ставку, нажать сильнее |
| circle back | вернуться к, обсудить позже |
| moving forward | дальше, начиная с этого момента |
| на той же странице (on the same page) | договорились, поняли друг друга |

## Шаблонные фразы (убрать)

Эти конструкции — с пустым местом под существительное или прилагательное — сигнал что предложение сгенерировано, а не написано.

- «В условиях современной цифровой экономики…» → начать с конкретного факта
- «В эпоху цифровой трансформации…» → убрать или назвать конкретный год/событие
- «В современном мире, где…» → убрать вводную, начать с сути
- «Данная статья рассмотрит / В этой статье мы рассмотрим» → убрать мета-нарратив, начать сразу с темы
- «Для того чтобы лучше понять, давайте рассмотрим…» → убрать, перейти сразу к сути
- «Независимо от того, являетесь ли вы [X] или [Y]» → ложная широта. Назови реальную аудиторию или убери
- «Было бы неверным утверждать, что…, однако…» → ложная уступка без конкретики. Займи позицию
- «Как мы все знаем…» → убрать; если все знают — зачем говорить
- «Ни для кого не секрет, что…» → то же самое

## Переходные фразы к переработке

- **«Таким образом»** в конце абзаца → убрать или переформулировать вывод конкретно
- **«В целом»** как заглушка → убрать или сказать конкретно что «в целом»
- **«Следовательно»** → «значит», «поэтому», «из этого следует»
- **«Помимо этого»** / **«Кроме того»** → «и», «также», «плюс», или перестроить так чтобы связь была очевидна
- **«В заключение»** / **«Подводя итоги»** → заключение должно быть понятно из структуры
- **«Что касается»** → перейди к теме напрямую
- **«В свете вышесказанного»** → убрать или сказать конкретно что имеется в виду
- **«На сегодняшний день»** → «сейчас», «сегодня» или конкретная дата

## Размытые ссылки

- «Эксперты считают», «Исследования показывают», «Специалисты утверждают» — без имён и источников → либо назвать конкретный источник, либо убрать атрибуцию и просто утверждать
- «По мнению ряда аналитиков» → то же самое
- «Согласно последним данным» → назвать источник или убрать

---

## Раздутые выводы

- «Будущее выглядит многообещающим», «Время покажет», «Одно можно сказать точно», «По мере развития технологий» — заглушки вместо выводов. Убрать. Если нужна заключительная мысль — сделать её конкретной для аргумента текста.
- «Мы находимся лишь в начале пути» → убрать или сказать конкретно начала чего и что дальше
- «Это открывает новые горизонты» → описать конкретно какие горизонты

## Артефакты чат-бота

- «Надеюсь, это помогло!», «Конечно!», «Разумеется!», «Отличный вопрос!», «Рад помочь!», «Не стесняйтесь задавать вопросы», «Если есть вопросы — пишите» → убрать полностью
- «В данной статье мы рассмотрим…» / «Давайте разберёмся…» / «Начнём с того, что…» — AI-мета-нарратив. Начни сразу с сути.
- «Итак, подведём итоги:» перед пересказом того что только что было написано → убрать, выводы должны быть понятны из текста

---

## Конструкции с «давайте»

«Давайте рассмотрим», «Давайте разберём», «Давайте посмотрим», «Давайте изучим» — AI использует «давайте» как ложно-коллегиальный затык перед переходом к теме. Это тянет время. Просто перейди к сути. «Давайте» уместно только как настоящее приглашение к действию, не как переход.

---

## Инфляция значимости

- «Это знаменует поворотный момент в развитии…», «переломный момент для отрасли» — раздуть рутинное событие до исторического. Напиши что произошло, читатель сам оценит.
- Если предложение работает после удаления «это знаменует…», удали.

---

## Излишняя академичность в разговорном тексте

Когда текст пишется для блога, телеграма или разговорного контекста, а AI использует официальный стиль:

- «В связи с вышеизложенным» → убрать или «поэтому»
- «На основании проведённого анализа» → «по результатам анализа» или «смотри выше»
- «Представленные данные свидетельствуют о» → «данные показывают»
- «Принимая во внимание» → «учитывая»

## Ложные крайности (lazy extremes)

AI любит подменять конкретику глобальными словами:

| Заменить | На |
|---|---|
| всегда / никогда (без оснований) | обычно, как правило, редко, почти никогда |
| каждый / любой / все | большинство, многие, часть, конкретная группа |
| вся индустрия / весь рынок | назови реальный сегмент |
| повсеместно | где конкретно |
| абсолютно (как усилитель) | убрать или конкретизировать |

Если «всегда» / «никогда» соответствует действительности — оставь. Если это риторический усилитель — заменяй на честную меру.
