# Proboi Skills

Открытые навыки (skills) для Claude Code и совместимых ИИ-ассистентов от команды [Proboi](https://proboi.site).

Skill в формате Claude Code — это папка с файлом `SKILL.md`, где описано, когда и как ассистенту себя вести в определённой ситуации. Ассистент сам подхватывает нужный навык по описанию в `description`. Подробнее про формат: [docs.claude.com — Agent Skills](https://docs.claude.com/en/docs/claude-code/skills).

## Что внутри

| Навык | Язык | Что делает |
|---|---|---|
| [`humanizer-ru`](humanizer-ru/) | русский | Аудит и переписывание русского текста для удаления AI-паттернов: канцелярита, клише, шаблонных конструкций, безличных глаголов. Есть режим detect-only — только подсветить проблемы без переписывания. |
| [`proboi-discovery`](proboi-discovery/) | русский | Глубокое исследование перед крупной или размытой задачей. С разрешения пользователя изучает контекст, при необходимости ищет в интернете, задаёт уточняющие вопросы, собирает спеку проекта на утверждение и только потом приступает к работе. Заточен под Telegram-бота с MCP-инструментами кнопок и отправки файлов. |

## Установка

### В Claude Code (любой проект)

Скопируй папку нужного навыка в директорию навыков своего проекта:

```bash
git clone https://github.com/Proboi-ai/proboi-skills.git
mkdir -p .claude/skills
cp -R proboi-skills/humanizer-ru .claude/skills/
```

Либо положи навык в глобальную папку `~/.claude/skills/`, чтобы он был доступен во всех проектах.

После этого Claude Code сам подхватит навык, когда твой запрос совпадёт с его описанием. Ничего вызывать вручную не нужно.

### Заметка про `proboi-discovery`

Этот навык рассчитан на инфраструктуру Telegram-бота Proboi и использует его MCP-инструменты (инлайн-кнопки `ask-user`, веб-поиск `batch-research`, отправку файлов `send-file`). В обычном Claude Code на компьютере имена инструментов другие, поэтому навык нужно будет адаптировать под свою среду. Подробности в [proboi-discovery/README.md](proboi-discovery/README.md).

`humanizer-ru` работает где угодно без зависимостей.
