# article-writing

Скилл для написания крутых статей и лонгридов, которые не звучат как AI-генерация. Собирает контекст, выбирает структуру, проверяет текст на AI-маркеры, правит ритм — и всё без воды и шаблонов.

## Зачем

AI-текст можно узнать за 2 секунды: ровные предложения, пафосные обобщения, «современный быстро меняющийся мир», «не просто X, а Y». Читатель чувствует — и листает дальше.

Этот скилл заставляет бота писать как человек: с ритмом, личными деталями, без AI-слов-паразитов и с правильной структурой.

## Что делает

- **Фреймворки структуры:** PAS, Hero's Journey, Before-After-Bridge, обратная пирамида
- **Открытия:** 4 типа хуков без «в современном мире»
- **AI-детокс:** вырезает 24+ паттерна AI-письма (отрицательные параллелизмы, правило трёх, em-dashes, AI-лексика)
- **Ритм текста:** чередование коротких/длинных предложений, парцелляция, анафоры
- **Чёрный список:** 100+ слов, которые только AI использует (delve, leverage, unlock, landscape...)
- **Чеклист на 10 пунктов** перед публикацией

## Установка

Скопируй папку в `<vault>/.claude/skills/article-writing/` или установи через `skill-installer` по URL репозитория.
