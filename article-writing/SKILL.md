# Скилл: Написание статей и лонгридов

Используй этот скилл когда пользователь просит написать или отредактировать статью, пост, эссе, лонгрид, аналитику — любой текст, который должен звучать как от человека, а не от нейросети.

## Режимы работы

**`rewrite`** (по умолчанию) — пишешь текст с нуля или переписываешь существующий, применяя все правила скилла.

**`detect`** — только флагируешь AI-паттерны, не переписываешь. Используй когда:
- Автор хочет сам решить, что менять
- Флаги могут быть намеренными (не все AI-паттерны плохи в малых дозах)
- Аудируешь чужой или опубликованный текст
- Нужна быстрая проверка без полного редактирования

Режим `detect` — когда пользователь говорит «только флаги», «только найди», «аудит», «проверь», «что здесь от AI». Иначе — `rewrite`.

## 1. Предварительный сбор (до написания)

Прежде чем писать, собери:

- **Целевая аудитория**: кому текст? (B2B-директора, тинейджеры, IT-специалисты)
- **Тон голоса**: формальный / разговорный / дерзкий / спокойный / экспертный
- **Главная мысль (тезис)**: что читатель должен запомнить после прочтения?
- **Личный опыт / примеры**: что пользователь лично видел/делал/пробовал по теме?
- **Болевые точки**: что беспокоит читателя по этой теме?
- **Триггер**: почему прямо сейчас, а не через месяц?

## 2. Структура статьи

### Открытие (Hook) — первые 10% текста

Четыре проверенных типа открытия:

1. **История/случай** — «Вчера я сидел с ноутбуком в кофейне и понял одну вещь...»
2. **Конфликт/боль** — «Ты тратишь часы на написание текстов, а тебя всё равно не читают.»
3. **Неожиданный факт** — «98% AI-текста можно узнать за 2 секунды. Вот как.»
4. **Вопрос с подвохом** — «Почему умные люди пишут скучные тексты?»

**Никогда** не начинай с: «В современном мире...», «С каждым днём...», «В данной статье мы рассмотрим...», «В эпоху цифровизации...», «Ни для кого не секрет...»

### Основная часть — 70-80% текста

Строится по одному из фреймворков:

**PAS (Problem-Agitate-Solution):**
- Опиши проблему читателя
- Усугуби её — покажи последствия бездействия
- Дай решение

**Hero's Journey (упрощённо):**
- Читатель сталкивается с вызовом
- Находит наставника/метод
- Применяет и трансформируется

**Обратная пирамида:**
- Самый важный вывод в начале
- Поддерживающие аргументы по убыванию важности
- Детали под кат

**Before-After-Bridge:**
- Как сейчас (боль)
- Как могло бы быть (идеал)
- Как туда попасть (мост)

### Закрытие — 10-15% текста

Конец должен быть сильным. Три варианта:

1. **Вывод + призыв к действию** — «В следующий раз, когда сядешь писать, вспомни три правила...»
2. **Круг** — Возврат к истории из начала с новым смыслом
3. **Открытый финал** — Сильная мысль без дожёвывания. Читатель сам додумывает.

**Никогда** не заканчивай:
- «В заключение хочется отметить...»
- «Надеюсь, эта статья была полезна...»
- «Если у вас есть вопросы, пишите в комментариях.»
- «Подводя итоги...»
- «Будущее выглядит многообещающим...»

Не разжёвывай вывод, который читатель уже сделал сам. Закончи на ноте, которая оставляет след, а не пересказывает всё заново.

## 3. Три абсолютных запрета (видимые AI-маркеры)

Эти три паттерна — самые узнаваемые признаки AI-текста в русском языке. Любой из них — провал.

### 🔴 Запрет 1: Длинное тире (—)

Самый узнаваемый AI-маркер в русском тексте 2024-2026. Любое длинное тире палит ИИ, даже если стилистически уместно.

**Заменять:**
- На дефис «-» (если короткое пояснение): «Proboi — это бот» → лучше переформулировать, но дефис допустим
- На двоеточие: «Готово: файл в чате»
- На точку и новое предложение: «Решение очевидно. Каждому свой контейнер.»
- На запятую + союз («то есть», «потому что», «а именно»)
- Просто убрать и переформулировать предложение

Исключений нет. Даже в прямой речи, пояснениях и противопоставлениях — найди другой способ.

### 🔴 Запрет 2: Антитеза «не X, а Y»

Конструкции вида «не отвечает, а делает», «не магазин, а песочница», «не просто X, а Y», «больше чем X», «нечто большее чем» — классический риторический паттерн ИИ.

**Вместо этого:**
- Скажи прямо что есть: «Бот выполняет задачи» (вместо «не отвечает, а делает»)
- Перенеси контраст в отдельное предложение: «Бот выполняет задачи. Это не просто чат-ассистент.»
- Просто убери первую часть: «Это песочница для экспериментов»

Также палит: «X — это не Y. Это Z», «не просто X».

### 🔴 Запрет 3: Микс английского и русского в терминах

Звучит как плохой технический перевод.

**Примеры:**
- «коммуникационный overhead» → «лишние круги согласования»
- «single shared container» → «один общий контейнер»
- «production-пользователь» → «реальный пользователь»
- «занавигировать сложности» → «разобраться со сложностями»

**Исключения:**
- Имена собственные: Linux, Docker, Telegram, Python
- Устоявшиеся техтермины без перевода: API, SDK, HTTP, JSON
- Цитаты кода: `docker exec`, `pip install`
- Названия концепций в кавычках при первом упоминании: «container escape» (дальше — «побег из контейнера»)

Правило: если есть русский эквивалент — используй русский.

## 4. AI-детокс. Лексика (словарь)

Слова разбиты на три уровня по надёжности сигнала.

### Уровень 1 — всегда заменять

Появляются в 5-20 раз чаще в AI-тексте, чем в человеческом.

| AI-слово | Заменить на |
|---|---|
| погрузиться / погружение | рассмотреть, разобрать, изучить |
| ландшафт (метафора) | рынок, среда, поле, область |
| нарратив | история, рассказ, точка зрения |
| экосистема (метафора) | система, сообщество, рынок, сеть |
| синергия / синергетический | (описать конкретный совместный эффект) |
| трансформация / трансформировать | изменение, перемена; изменить, перестроить |
| цифровизация | (описать конкретно что оцифровывается) |
| парадигма | модель, подход, принцип |
| комплексный / комплексно | полный, всесторонний — или описать что включено |
| актуальный / актуальность | важный, нужный, своевременный |
| оптимальный | лучший, подходящий, наиболее работающий |
| инновационный / инновация | новый, передовой — или описать что нового |
| уникальный | (сказать чем конкретно отличается) |
| стратегический | (описать реальную стратегию или убрать) |
| масштабирование / масштабировать | рост, расширение; вырасти, расширить |
| бесшовный / бесшовно | плавный, без трений, без разрывов |
| функционал | функции, возможности, инструменты |
| взаимодействие (штамп) | работа, связь, общение — или конкретный глагол |
| дорожная карта (метафора) | план, список задач, расписание |
| прозрачный (метафора) | открытый, честный, понятный |
| устойчивый (не о физике) | стабильный, долгосрочный, надёжный |
| ключевой (как усилитель) | главный, основной, важный — или убрать |
| глубокое погружение | подробный разбор, детальный анализ |
| эффективный / эффективно | работающий, результативный — или сказать как именно |
| проактивный | (описать конкретное действие вместо слова) |
| холистический | полный, целостный — или описать что включено |
| релевантный | подходящий, важный, нужный |
| значимый / значимость | важный — или описать конкретно |

### Уровень 2 — флаговать при 2+ в одном абзаце

По отдельности допустимы, два и больше в одном абзаце — сигнал AI.

| AI-слово | Заменить на |
|---|---|
| формировать | создавать, делать, выстраивать |
| обеспечить (в смысле «достичь») | добиться, получить, дать |
| реализовать | сделать, запустить, воплотить |
| осуществить | сделать, провести, выполнить |
| имплементировать | ввести, запустить, применить |
| интегрировать | включить, добавить, встроить |
| оптимизировать | улучшить, ускорить, упростить |
| мониторить | следить, отслеживать |
| аналитика (как общее слово) | данные, статистика, цифры |
| консолидация | объединение; объединить |
| контекст (как затычка) | (убрать или уточнить какой контекст) |
| подход (без конкретики) | (описать конкретный метод) |
| методология | метод, способ, подход |
| концепция (без конкретики) | идея, принцип, план |
| сценарий (без конкретики) | случай, ситуация, вариант |
| фреймворк | система, структура, модель |
| инструментарий | инструменты, набор |

### Уровень 3 — флаговать по плотности

Обычные слова, которые AI просто переиспользует. Флаговать только при насыщении (~3%+ слов текста).

| Слово | Что делать |
|---|---|
| важный / важно | Часть заменить на конкретику: числа, примеры |
| существенный / существенно | Описать насколько и почему |
| современный | Назвать конкретный год или период |
| передовой | Сослаться на конкретный пример |
| эффективный | Описать как именно или привести метрику |
| успешный / успешно | Описать что говорит об успехе |
| активный | Сказать что конкретно происходит |

### Канцелярит

Русский AI любит официально-деловой стиль там, где он не нужен.

| Фраза | Заменить на |
|---|---|
| «является оптимальным» | «этот подход — лучший» / «этот подход работает» |
| «данный / данная / данное» | «этот / эта / это» или «вот» |
| «осуществить переход» | «перейти» |
| «реализовать проект» | «сделать проект» / «запустить проект» |
| «обеспечивает возможность» | «позволяет» |
| «в рамках данной статьи» | «в этой статье» |
| «проведение анализа» | «анализ» |
| «вышеизложенное / нижеследующее» | убрать, указать конкретно |

### Слова-маркеры уверенности (убрать)

AI использует их чтобы звучать значительнее — они добавляют слова, не добавляя смысла.

«Безусловно», «несомненно», «очевидно», «стоит отметить», «следует отметить, что», «важно подчеркнуть», «нельзя не отметить», «необходимо учитывать, что», «как было отмечено выше».

Все — убрать. Если что-то очевидно — просто скажи факт.

### Переходные фразы-заглушки

«Таким образом» → убрать или конкретный вывод.
«В целом» → убрать или сказать конкретно.
«Следовательно» → «значит», «поэтому».
«Помимо этого» / «Кроме того» → «и», «также», «плюс».
«В заключение» / «Подводя итоги» → заключение должно быть понятно из структуры.
«Что касается» → перейди к теме напрямую.
«На сегодняшний день» → «сейчас», «сегодня».
«В свете вышесказанного» → убрать.

### Размытые ссылки

«Эксперты считают», «Исследования показывают», «Специалисты утверждают» — без имён и источников. Либо назови конкретный источник, либо убери атрибуцию и просто утверждай.

### Артефакты чат-бота

«Надеюсь, это помогло!», «Конечно!», «Разумеется!», «Отличный вопрос!», «Рад помочь!», «Не стесняйтесь задавать вопросы», «Конечно, вот...» — убрать полностью.

«Давайте рассмотрим», «Давайте разберём», «Давайте посмотрим» — AI использует «давайте» как ложно-коллегиальный затык перед переходом. Просто перейди к сути.

### Инфляция значимости

«Это знаменует поворотный момент», «переломный момент для отрасли», «открывает новые горизонты», «будущее выглядит многообещающим», «время покажет», «одно можно сказать точно» — раздуть рутинное событие до исторического. Напиши что произошло, читатель сам оценит.

## 5. AI-детокс. Структурные паттерны

Проблемы не в словах, а в том, как построены предложения. Если исправить всю лексику по разделу 4, но оставить структуру нетронутой — текст всё равно читается как сгенерированный.

### False Agency — ложная агентность

Главный структурный AI-шизм. AI приклеивает активные глаголы к неодушевлённым подлежащим — это уводит от вопроса «а кто это сделал».

| Плохо | Хорошо |
|---|---|
| «решение принимается» | Кто-то решает. Назови кто. |
| «культура трансформируется» | Люди меняют поведение. |
| «данные говорят» / «цифры рассказывают» | Кто-то читает данные и делает вывод. |
| «рынок диктует» | Покупатели платят за то, что хотят. |
| «технология меняет жизнь» | Люди применяют технологию — и от этого жизнь меняется. |
| «история показывает» | Ты показываешь, ссылаясь на пример. |
| «опыт подсказывает» | Кто-то на основе опыта делает вывод. |
| «реальность такова» | Не реальность, а ты говоришь. |

**Как чинить:** найди человека (или конкретную систему), сделай его подлежащим, переведи глагол в активный залог.

**До:** «Решение о переходе на новую архитектуру принимается на основе анализа нагрузки.»
**После:** «Мы переходим на новую архитектуру, когда видим устойчивый рост нагрузки.»

### Голос-наблюдатель (narrator-from-a-distance)

Текст пишется «с высоты», без человека в кадре. AI любит этот тон — он звучит «весомо» и ни к чему не обязывает.

| Плохо | Хорошо |
|---|---|
| «Принято считать, что...» | Кем принято? Назови или удали. |
| «Многие склонны думать, что...» | Размытая ссылка. |
| «Общество движется к...» | Кто конкретно двигается? |
| «Человечество стоит на пороге...» | Скажи конкретно про чью-то ситуацию. |
| «В современном мире наблюдается тенденция...» | Кто наблюдает? |
| «Никто не любит, когда...» | Скажи «ты» или конкретного человека. |
| «История знает примеры...» | Убери интро, дай сам пример. |

**Как чинить:** замени голос-наблюдателя на «ты» (если совет читателю), «я» (если личный опыт), или конкретного человека/команду (если кейс).

**До:** «Принято считать, что переход на удалёнку повышает продуктивность.»
**После:** «Команды на удалёнке часто показывают лучшие метрики — GitLab за 2024 год отчитался о росте velocity на 18%.»

### Пассивный залог без причины

AI злоупотребляет пассивным залогом чтобы звучать официально.

«было установлено» → «мы установили»
«является необходимым» → «нужно»
«должно быть учтено» → «учти»
«может быть использован» → «можно использовать»
«был разработан» → «разработали» (если известно кто)

Оставляй пассивный залог когда деятель реально неизвестен или когда формальный тон уместен по жанру (документация, юридический текст).

### Отглагольные существительные вместо глаголов

AI превращает глаголы в существительные — это делает текст тяжелее.

«осуществление мониторинга» → «мониторить»
«проведение анализа» → «анализировать»
«выполнение задач» → «выполнять задачи»
«принятие решений» → «принимать решения»
«обеспечение роста» → «расти»

### Бинарные противопоставления

Создают ложную драму. Скажи сразу что хотел.

«Проблема не в X. Проблема в Y.» → Скажи Y напрямую.
«Дело не в X, а в Y.» → Скажи Y напрямую.
«Это не X. Это Y.» → Скажи Y.
«Кажется, что X. На самом деле Y.» → Скажи Y.
«Вопрос не в X. Вопрос в Y.» → Скажи Y.

### Негативное перечисление

Перечислять что вещь *не есть* перед тем как сказать что она *есть*.

«Не X... Не Y... А Z.» → Сразу Z. Читателю не нужна разбежка.

### Драматическая фрагментация

Обрубленные фразы для искусственной многозначительности.

«[Слово]. И всё. Вот и весь секрет.» → Полное предложение. Доверяй содержанию, а не подаче.
«X. И Y. И Z.» → То же.
«Это меняет всё. Полностью.» → Искусственное откровение. Убрать.

### Риторические сетапы

Анонсируют инсайт вместо того чтобы его дать.

«А что если бы X?» (как переход) → сделай вывод.
«Сейчас объясню что имею в виду» → лишний анонс.
«Подумайте об этом» → снисходительный жест.
«И это нормально.» → лишнее разрешение.

### Ложная широта

AI создаёт иллюзию охвата парами несвязанных крайностей: «от стартапов до корпораций», «от рядовых сотрудников до топ-менеджмента». Назови реальные темы или выбери одну.

### Оценочная нейтральность

AI до изнеможения нейтрален. Там где текст должен иметь позицию — он уклоняется.

«С одной стороны..., с другой стороны...» без вывода → занять позицию.
«Можно рассмотреть несколько точек зрения» → сказать какая из них лучше и почему.
Отсутствие «я думаю», «по-моему», «на мой взгляд» там где они уместны — тоже AI-сигнал.

Цель — не безличная объективность, а честная субъективность. Читатель верит человеку с позицией, а не машине, которая перечисляет варианты.

## 6. Паттерны живого письма

Текст звучит как от человека, а не от нейросети, когда в нём есть эти семь вещей.

### 1. Детали вместо оценок

Не пиши вывод за читателя. Покажи деталь — читатель сам сделает вывод.

❌ «Она была расстроена.»
✅ «Она молча комкала салфетку и смотрела в окно.»

❌ «Сервис был ужасный.»
✅ «Официант принёс холодный кофе дважды и пропал на сорок минут.»

Доверяй читателю. Конкретная деталь сильнее любой оценки.

### 2. Объективность без пафоса

Автор-наблюдатель. Покажи что происходит, не навешивай оценок.

❌ «Это невероятно важное открытие, которое коренным образом меняет наше представление о мире.»
✅ «После этого эксперимента группа смогла повторить результат в 8 из 10 случаев.»

Читатель сам решит, насколько это важно. Твоя задача — дать факты.

### 3. Конкретные бытовые детали

Не «в ресторане», а «в трактире с засаленной скатертью и мухами на варенье».
Не «в офисе», а «в комнате, где пахнет старым кофе и гудит кондиционер».
Не «инструмент для анализа», а «скрипт на Python, который парсит 500 страниц за минуту».

Бытовая конкретика — самый быстрый способ сделать текст осязаемым. Одна конкретная деталь заменяет абзац общих слов.

### 4. Нефункциональные детали

Не каждая деталь должна работать на главную мысль. Иногда деталь просто создаёт ощущение реальности.

Человек, рассказывая историю, запоминает случайные вещи: «он вытряхнул песок из сапога и продолжил говорить», «лакей уронил поднос именно с ветчиной с горошком». Эти детали не несут смысла — они создают иллюзию того, что текст писал живой свидетель, а не генератор, оптимизирующий каждое слово под задачу.

Используй нефункциональные детали дозированно: одна-две на весь текст. Они ломают «слишком гладкий» нарратив и делают его человечным.

### 5. Речевая характеристика вместо портрета

Человек раскрывается через то, как он говорит, — а не через описание автором.

❌ «Иван был грубым и нетерпеливым начальником.»
✅ «— Ну и где этот отчёт? Я жду. У меня нет времени. Совсем. Ну?»

По реплике можно восстановить характер, профессию, настроение. Строй диалоги так, чтобы читатель видел человека без подсказок автора.

### 6. Многослойность и противоречия

Никаких однозначных персонажей, ситуаций или выводов. Реальный опыт — это всегда сложнее, чем «хорошо против плохо».

❌ «Он был настоящим профессионалом и всегда поступал правильно.»
✅ «Он знал свою работу лучше всех в отделе. И при этом умудрялся опаздывать на каждую планерку.»

Противоречие — признак живого текста. Не сглаживай углы. Они делают историю правдивой.

### 7. Экономия средств

Одна точная деталь работает сильнее, чем три расплывчатых. Один эпитет, одна метафора, один образ. Если слово можно вырезать — вырежь. Каждое слово должно быть нагружено.

После каждого абзаца спроси себя: «Что изменится, если этот абзац убрать?» Если ничего — убирай.

## 7. Ритм текста (Sentence Rhythm)

Ключевой приём, который отличает профессиональный текст от AI. AI-текст метрономичен; человеческий — с переменным ритмом.

### Чередование длины предложений

- **Длинные (15+ слов)** — для сложных идей, описания сцен, нагнетания
- **Средние (6-14 слов)** — основное повествование
- **Короткие (1-5 слов)** — удары, выводы, перевороты

**Паттерн: длинное → короткое** (эффект хука)
> «Текст, написанный нейросетью, можно узнать за полсекунды. Он слишком ровный.»

**Паттерн: короткое → длинное** (контекст)
> «Он ошибался. Дело в том, что за два года работы с клиентами я ни разу не видел, чтобы стратегия сработала без личного примера автора.»

Неполные предложения — нормально. Вопросы разбивают монотонность. Длинные и короткие должны чередоваться без системы — как в живой речи.

### Абзацы

- Максимум 4-5 предложений
- Минимум — 1 предложение (для акцента)
- Каждый абзац — одна законченная мысль
- Чередуй длину абзацев для динамики
- Если каждый абзац ровно 3-5 предложений — поломай ритм намеренно

### Ритмические приёмы

- **Анафора** — повтор начала предложений («Я хочу, чтобы... Я хочу, чтобы...»)
- **Инверсия** — нарушение порядка слов для акцента
- **Парцелляция** — дробление на несколько предложений («Он пришёл. Увидел. Победил.»)
- **Короткий абзац-акцент** — одно предложение как отдельный абзац

### Структура — сигнал №1

Равномерное построение предложений, одинаковый темп, симметричные конструкции тяжелее замаскировать, чем несколько замен слов. Если исправить весь Уровень 1 словаря, но оставить ритм нетронутым — текст всё равно читается как сгенерированный.

## 8. Сторителлинг (Storytelling)

Пять работающих схем для любой статьи.

### 1. «Проблема → Борьба → Инсайт → Решение»
Ты сталкиваешься с проблемой. Пытаешься её решить — не получается. Находишь инсайт. Применяешь. Работает.

### 2. «Ошибка → Осознание → Исправление»
Я делал X годами. Потом понял, что это неправильно. Вот что я изменил.

### 3. «Общеизвестное → Оспаривание → Новая правда»
Все говорят X. Но на самом деле Y. Вот доказательства.

### 4. «До и После»
Вот как было (проблемы). Вот как стало (результат). Вот что для этого сделали.

### 5. «Конкретный кейс → Универсальный урок»
История одного человека/компании → общий принцип.

**Важно:** любая схема работает только с конкретными деталями. Если убрать имена, цифры, обстоятельства — останется каркас, а не история.

## 9. Система скоринга (P0/P1/P2)

### P0 — Убийцы доверия (исправить немедленно)
- Длинное тире (—) в любом виде
- Антитеза «не X, а Y» и её варианты
- Микс английского и русского в терминах
- Артефакты чат-бота («Отличный вопрос!», «Надеюсь, помог!»)
- Размытые ссылки без источника («Эксперты считают»)
- Инфляция значимости на рутинных событиях
- Мета-нарратив («Данная статья рассмотрит», «Давайте разберёмся»)
- False agency на ключевых утверждениях («решение принимается» в тексте про управление)

### P1 — Очевидный AI-запах (исправить до публикации)
- Уровень 1 словарь (погрузиться, экосистема, трансформация, парадигма, функционал)
- Шаблонные вступления («В современном мире…», «В эпоху цифровизации…»)
- Канцелярит (являться, осуществлять, в рамках, данный)
- Уверенность-заглушки (безусловно, стоит отметить)
- Отглагольные существительные цепочками
- Раздутые выводы («будущее выглядит…», «время покажет»)
- Голос-наблюдатель издалека
- Ложные крайности (всегда/никогда/любой) в обозримых утверждениях

### P2 — Стилистическая полировка (исправить когда есть время)
- Равномерная длина абзацев и предложений
- Риторические вопросы как затычки
- Переходы-заглушки (таким образом, в целом, помимо этого)
- Излишняя академичность в разговорном контексте
- Оценочная нейтральность (отсутствие позиции)
- Повторение перефразом (три синонима подряд)

**P0+P1 — обязательный проход перед сдачей. P2 — когда есть время.**

## 11. Быстрый чеклист перед отправкой

### 🔴 Три абсолютных (P0)
- [ ] Нет длинного тире (—) — ни одного.
- [ ] Нет антитез «не X, а Y» — ни одной.
- [ ] Нет микса английского и русского в терминах.

### AI-детокс (P0+P1)
- [ ] Нет слов Уровня 1 (погрузиться, экосистема, ландшафт, парадигма, трансформация, функционал)
- [ ] Нет канцелярита (является, осуществляется, в рамках, данный)
- [ ] Нет шаблонного вступления («В современном мире», «Данная статья рассмотрит»)
- [ ] Нет уверенности-заглушек (безусловно, стоит отметить, важно подчеркнуть)
- [ ] Нет размытых ссылок без источников
- [ ] Нет инфляции значимости на рутинных событиях
- [ ] Нет артефактов чат-бота («Конечно!», «Надеюсь, помог!»)

### Структура (P1)
- [ ] Нет false agency — у каждого глагола есть конкретный актор
- [ ] Нет голоса-наблюдателя — текст не с высоты, а «ты» / «я» / конкретный человек
- [ ] Нет бинарных противопоставлений и негативных перечислений
- [ ] Нет ложной нейтральности — у текста есть позиция

### Паттерны живого письма
- [ ] Детали вместо оценок — нигде не сказано «это было ужасно/прекрасно», вместо этого конкретика
- [ ] Хотя бы одна конкретная бытовая деталь
- [ ] Есть личный пример или конкретный кейс с цифрами/именами
- [ ] Нет пафоса и раздутой значимости

### Ритм
- [ ] Есть короткие предложения после длинных
- [ ] Не все абзацы одинаковой длины
- [ ] Нет «правила трёх» везде подряд — где-то два пункта, где-то четыре

### Финальный аккорд
- [ ] Последний абзац сильный — не сливается, не пересказывает, а бьёт
- [ ] Нет «в заключение хочется отметить», «надеюсь, было полезно»
- [ ] Концовка не разжёвывает то, что читатель уже понял

### Финальный тест
- [ ] Текст прочитан вслух — если спотыкаешься, перепиши
- [ ] Если показать кому-то — не скажут «это ChatGPT писал?»
- [ ] В тексте есть хотя бы одна шероховатость, нестандартность, которая не даёт ему быть «слишком гладким»

## 12. Рабочий процесс

1. **Сбор** (раздел 1) — контекст, ЦА, тезис, боли, примеры
2. **План** — только тезисы, никакого текста. Выбери структуру (раздел 2)
3. **Грязный черновик** — пиши не останавливаясь, не редактируй. Следи за тремя абсолютными запретами.
4. **Проверка P0** — три абсолютных запрета (длинное тире, антитезы, микс англ/рус), false agency, артефакты чат-бота
5. **Проверка P1** — словарь Уровень 1, канцелярит, шаблонные вступления, голос-наблюдатель, размытые ссылки
6. **Полировка P2** — ритм, длина абзацев, переходы, нейтральность
7. **Паттерны живого письма** — проверь что есть детали (не оценки), конкретика, хотя бы одна нефункциональная деталь, речевая характеристика, многослойность
8. **Финальный чеклист** (раздел 11)
9. **Дать отлежаться** — минимум 30 минут, потом финальный взгляд и чтение вслух
