# proboi-discovery

Облегчённый аналог dev-скилла `task-discovery`, заточенный под Telegram-бота. Заставляет бота на крупной или размытой задаче сначала **исследовать**, а не угадывать: с разрешения юзера он изучает его прошлые материалы (память + файлы), при необходимости ищет в интернете, задаёт 2-4 уточняющих вопроса кнопками, присылает спеку проекта txt-файлом на утверждение — и только после «да» начинает делать результат.

## Зачем

На больших задачах («сделай проект», «нужна стратегия», «сделай как лучше») модель часто кидается делать наугад и попадает мимо — приходится переделывать, что жжёт время и кредиты. Этот скилл вставляет короткую фазу исследования + явное утверждение спеки перед работой. Результат с первого раза точнее.

Дорогую процедуру запускает **сам юзер** — бот только предлагает кнопкой «Хочешь, проведу исследование?». «Нет» уважается мгновенно.

## Поток

```
Шаг 0: фильтр — простая задача? делай сразу, скилл не нужен
  ↓ крупная/размытая
Спросить разрешение (кнопки Да/Нет)
  ↓ Да
Изучить память + файлы юзера → решить, нужен ли интернет → искать
  ↓
2-4 уточняющих вопроса кнопками (по одному за ход)
  ↓
Собрать спеку → отправить txt-файлом → спросить «утверждаешь?» (кнопки)
  ↓ Да
Выполнить строго по спеке
```

## Зависимости среды (важно)

Скилл рассчитан на инфраструктуру Telegram-бота Proboi и использует три его MCP-инструмента:

- `mcp__ask-user__ask_user(question, options[])` — инлайн-кнопки. После вызова ход обрывается, ответ приходит следующим сообщением.
- `mcp__batch-research__search` / `mcp__batch-research__fetch` — веб-поиск (НЕ `WebSearch`).
- `mcp__send-file__send_file(file_path, caption)` — отправка файла (спеки) юзеру.

Плюс память юзера (`MEMORY.md` + `memory/`) и его файлы в рабочей директории (vault). Вне этой среды (например в обычном Claude Code на ноуте) имена инструментов другие — скилл придётся адаптировать.

Только paid-тариф: free-юзеры не имеют контейнера и Bash, скилл у них не активируется.

## Установка

Это **opt-in** скилл — он сознательно лежит вне `claude-skills/`, поэтому `scripts/install-cc-skills.sh` его НЕ раздаёт всем автоматически.

- **Раздать всем paid:** перенеси папку в `claude-skills/proboi-discovery/`, задеплой, запусти `bash scripts/install-cc-skills.sh`.
- **Поставить себе / выдать по запросу:** скопируй папку в `<vault>/.claude/skills/proboi-discovery/` (или установи через `skill-installer` по GitHub-URL).
