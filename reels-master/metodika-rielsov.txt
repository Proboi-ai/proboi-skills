# Методика вирусных рилс — полная референсная система

Собрана и обобщена из десятков открытых источников, публичных исследований алгоритмов платформ (Meta, TikTok, YouTube), практических кейсов и собственных наблюдений. Никаких слитых курсов — только публично доступная информация.

---

## 1. ЯДРО СИСТЕМЫ: Viral Reel Framework (VRF)

Любой вирусный рилс строится по трёхактной структуре, где каждый блок решает строго свою задачу и работает на удержание:

```
┌─────────────────────────────────────────────────────────┐
│                    VRF — THREE-BLOCK ENGINE               │
├─────────────────────────────────────────────────────────┤
│  BLOCK 1: HOOK (0–3 сек)                                 │
│  └─ Остановить скролл. Разрыв ожидания. Эмоция.         │
│                                                          │
│  BLOCK 2: CORE VALUE (3–12/20 сек)                       │
│  └─ Выполнить обещание хука. Дать ценность.              │
│                                                          │
│  BLOCK 3: CTA (последние 3–5 сек)                        │
│  └─ Направить энергию: подписка / коммент / сохранение   │
└─────────────────────────────────────────────────────────┘
```

### Нормативы слов по таймингу (средняя скорость речи — 2.8–3.2 слова/сек)

| Тип рилса | Длина | Всего слов | Хук | Core | CTA |
|-----------|-------|------------|-----|------|-----|
| Микро     | 15 сек | 40–50     | 9–12 | 22–30 | 9–12 |
| Стандарт  | 30 сек | 80–100    | 9–12 | 55–75 | 12–15 |
| Средний   | 45 сек | 120–140   | 9–12 | 95–115 | 12–15 |
| Длинный   | 60 сек | 160–180   | 9–12 | 130–150 | 15–20 |

## 2. ИНЖИНИРИНГ ХУКОВ: Attention Matrix

### 2.1 12 базовых архетипов хуков

| # | Архетип | Формула | Психологический триггер |
|---|---------|---------|------------------------|
| 1 | **Тайна** | «Ты знал, что [факт]?» | Любопытство / информационный разрыв |
| 2 | **Список** | «[N] [шокирующих] фактов о [тема]» | Структурированность + FOMO |
| 3 | **Ошибка** | «[N] ошибок, которые ты делаешь с [тема]» | Боль + авторитет |
| 4 | **Шок** | «Ты не поверишь, [что произошло]» | Эмоциональный разрыв |
| 5 | **Прямое обращение** | «Если ты [ЦА], останови скролл» | Персонализация |
| 6 | **Трансформация** | «Я прошёл путь от X к Y за [время]» | Социальное доказательство + aspiration |
| 7 | **Эксклюзив** | «Только 1% знает [инсайт]» | Статус + эксклюзивность |
| 8 | **Контроверсия** | «Всё, что ты знал о X — неправда» | Когнитивный диссонанс |
| 9 | **FOMO** | «Ты слышал про [новинку]?» | Страх упустить |
| 10 | **Срочность** | «Прежде чем [действие], посмотри это» | Дефицит времени |
| 11 | **Провал** | Личная история с цифрами | Уязвимость + доверие |
| 12 | **Контраст** | До/после в первом кадре | Визуальный разрыв |

### 2.2 Продвинутые техники хуков для 2026

**Pattern Interrupt (разрыв шаблона)**
- Визуальный: резкая смена света/цвета/движения в первом кадре
- Аудиальный: неожиданный звук, пауза, смена темпа
- Концептуальный: начать с результата, не показывая процесс
- Социальный: нарушить неписаное правило ниши

**Curiosity Gap (информационный разрыв)**
- Сообщить факт, но не раскрыть полностью
- Начать с середины истории
- Показать результат, скрыв причину
- Задать вопрос, ответ на который неочевиден

**Emotional Flash (эмоциональная вспышка)**
- Шок: показать неожиданную статистику
- Гнев: указать на несправедливость
- Радость: неожиданный позитив
- Страх: показать последствие бездействия

### 2.3 Тест качества хука (Hook Score)

Каждый хук оценивается по 4 параметрам (1–10):

| Параметр | Что измеряет | Нижняя граница |
|----------|-------------|----------------|
| **Curiosity** | Создаёт ли вопрос в голове? | ≥ 7 |
| **Specificity** | Есть ли конкретика (цифры, имена)? | ≥ 6 |
| **Relatability** | Узнаёт ли зритель себя? | ≥ 7 |
| **Pacing** | Влезает ли в 3 сек при чтении вслух? | бинарно |

**Hook Score = (Curiosity × 0.35 + Specificity × 0.25 + Relatability × 0.40) × Pacing**

Проходной балл: ≥ 7.0. Если ниже — хук не используется.

## 3. АРХИТЕКТУРА УДЕРЖАНИЯ: Retention Engineering

### 3.1 Механики удержания внимания

| Приём | Как работает | Эффект |
|-------|-------------|--------|
| **Смена кадра каждые 2–4 сек** | Мозг не успевает привыкнуть | +25–40% watch time |
| **Jump cuts** | Убирают паузы, ускоряют темп | +15–20% retention |
| **Текстовые плашки на весь экран** | Для 30–40% зрителей без звука | +20–30% completion |
| **Открытый цикл (open loop)** | «Но есть одна проблема...» — заставляет досмотреть | +35–50% retention |
| **Субтитры с выделением ключевых слов** | Фиксируют взгляд на экране | +10–15% AVD |
| **Эмоциональные качели** | Смех → боль → инсайт → призыв | +20–30% engagement |
| **Топливо для комментариев** | Вопрос или опрос внутри сценария | +40–60% comments |
| **Loop-финал** | Концовка, зацикливающаяся на начало | +15–25% replays |

### 3.2 Структура удержания по секундам (15-сек рилс)

```
Сек 0–1:   Визуальный/аудиальный pattern interrupt
Сек 1–3:   Хук + текстовая плашка (ключевые слова выделены)
Сек 3–4:   Смена кадра + усиление
Сек 4–7:   Развитие: проблема/боль, узнаваемая ситуация
Сек 7–8:   Поворотный момент (открытый цикл / неожиданность)
Сек 8–11:  Решение/ценность
Сек 11–12: Микро-пауза перед CTA
Сек 12–15: CTA + визуальный акцент (стрелка, кнопка)
```

### 3.3 Критические точки провала внимания (drop-off zones)

| Точка | Причина ухода | Как бороться |
|-------|--------------|--------------|
| 0–1 сек | Непонятно, о чём видео | Pattern interrupt в первом кадре |
| 3–4 сек | Хук не выполнил обещание | Проверка Hook Score |
| 7–9 сек | Потеря темпа, «вода» | Jump cut, убрать паузы |
| 12+ сек | Нет открытого цикла | Не закрывать смысл до конца |

## 4. АЛГОРИТМИЧЕСКАЯ МОДЕЛЬ: как платформы ранжируют рилсы

### 4.1 Instagram Reels (2026)

**Система распределения: стадиальная**

```
Stage 1: Initial Test Pool (30–60 мин после публикации)
  └─ Показ 500–2000 зрителям (фолловеры + non-followers)
  └─ Сбор сигналов

Stage 2: Evaluation
  └─ Измерение: Shares > Watch-through rate > Saves > Replay rate
  └─ Сравнение с другими рилсами в этом же временном слоте

Stage 3: Expansion (если сигналы сильные)
  └─ Рилс попадает в Reels tab + Explore
  └─ Масштабирование по мере удержания engagement

Stage 4: Evergreen Resurfacing
  └─ Рилс может вернуться в выдачу через дни/недели
  └─ Триггер: новые сохранения или шеры
```

**Вес сигналов ранжирования (2026):**

| Сигнал | Вес | Почему |
|--------|-----|--------|
| Shares (отправка в DM) | ★★★★★ | Самый сильный сигнал одобрения |
| Watch-through rate | ★★★★☆ | Полный досмотр = высокая ценность |
| Saves | ★★★★☆ | Намерение вернуться |
| Replay rate | ★★★☆☆ | Двойной просмотр |
| Comments | ★★★☆☆ | Активное вовлечение |
| Likes | ★★☆☆☆ | Минимальный сигнал |
| Shares (repost) | ★★☆☆☆ | Ниже, чем DM share |

**Ключевое изменение 2026:** Оригинальность контента > репосты и тренды. Аутентичный контент работает в 2 раза лучше постановочного. Recycled trends потеряли 40–60% охвата с сентября 2025.

### 4.2 TikTok

**Система:** For You Page (FYP) — полностью рекомендательная
**Ключевые сигналы:**
- Completion rate (особенно для видео < 30 сек)
- Re-watch rate (повторный просмотр = сильнейший сигнал)
- Time spent per view (абсолютное время)
- Shares (внутренние + внешние)

**Особенности:**
- Более агрессивное тестирование на новой аудитории
- Выше чувствительность к трендам и звукам
- Алгоритм быстрее «холодно» тестирует контент

### 4.3 YouTube Shorts

**Система:** Двухфакторная — рекомендации + поиск
**Ключевые сигналы:**
- Early retention (первые 30 секунд)
- Swipe-away rate (процент пролистываний)
- Частота просмотров на сессию
- CTR (кликабельность в Suggested Videos)

**Ключевое отличие:** Shorts индексируются в поиске. SEO-оптимизация (название, описание) даёт дополнительный органический трафик, которого нет на IG/TikTok.

## 6. СИСТЕМА НАПИСАНИЯ СЦЕНАРИЯ (8-шаговый алгоритм)

Полный цикл от идеи до готового сценария:

```
ШАГ 1: ЦЕЛЬ (30 сек)
  └─ Выбрать ОДНУ метрику: охваты / подписки / продажи / сохранения
  └─ Цель определяет формат, тон и CTA

ШАГ 2: ФОРМАТ (1 мин)
  └─ Выбрать формат подачи под цель:
     • Список      → обучение, лайфхаки, топы
     • Процесс     → демонстрация, инструменты, настройки
     • Сторителлинг → личный бренд, кейсы
     • До/после    → результаты, трансформация
     • Сравнение   → обзоры, выбор
     • Разбор      → экспертный контент, аналитика

ШАГ 3: ХУК (3 мин)
  └─ Написать 5–10 вариантов хука
  └─ Выбрать лучший по Hook Score (≥ 7.0)
  └─ Проверить: остановился бы я сам?

ШАГ 4: БОЛЬ/ПРОБЛЕМА (2 мин)
  └─ Усилить знакомую боль / создать напряжение
  └─ Использовать психологический триггер из пула:
     Боль → Жадность → Любопытство → Эксклюзив
     → Социальное доказательство → Авторитет → Дефицит

ШАГ 5: РЕШЕНИЕ/ЦЕННОСТЬ (3 мин)
  └─ Выполнить обещание хука
  └─ Каждый слой = новая порция информации (каждые 2–3 сек)
  └─ Если список: 3–5 пунктов максимум

ШАГ 6: CTA (1 мин)
  └─ Выбрать тип CTA под цель:
     • Комментарий  → Comments    «Напиши в комментах...»
     • Сохранение   → Saves       «Сохрани, чтобы не потерять»
     • Подписка     → Follows     «Подпишись, чтобы не пропустить»
     • Репост       → Shares      «Отправь тому, кому это нужно»
     • Диалог       → Engagement  «Кто согласен — 🔥, кто нет — 👇»

ШАГ 7: ТАЙМИНГ (1 мин)
  └─ Прочитать вслух с секундомером
  └─ Подрезать лишнее (каждое лишнее слово = потеря внимания)
  └─ Проверить плотность: в идеале 1 мысль на 5–7 сек

ШАГ 8: АДАПТАЦИЯ ПОД ПЛАТФОРМУ (30 сек)
  └─ Проверить по платформенному плейбуку (раздел 5)
  └─ Длина хука под платформу
  └─ Формат CTA под поведение аудитории
```

Общее время: ~12 минут на один готовый сценарий.

## 8. ПСИХОЛОГИЧЕСКИЕ ТРИГГЕРЫ (7 рычагов влияния)

```
БОЛЬ       → «Устал платить за 7 подписок?»
ЖАДНОСТЬ   → «Одна подписка вместо семи»
ЛЮБОПЫТСТВО → «Ты не поверишь, что делает этот бот»
ЭКСКЛЮЗИВ  → «Функция, которую почти никто не использует»
СОЦ. ДОКАЗАТЕЛЬСТВО → «5000 пользователей уже перешли»
АВТОРИТЕТ  → «Я создал этот бот и расскажу как»
ДЕФИЦИТ    → «Только до конца месяца по старой цене»
```

**Правило последовательности:** В одном рилсе использовать 2–3 триггера, выстроенных по принципу: боль → жадность → дефицит.

## 9. ПРОИЗВОДСТВЕННЫЙ ЦИКЛ И ТЕСТИРОВАНИЕ

### 9.1 Оптимальная частота публикаций

| Уровень | Instagram | TikTok | YouTube Shorts |
|---------|-----------|--------|----------------|
| Старт (0–3 мес) | 4–5/нед | 5–7/нед | 3–4/нед |
| Рост (3–12 мес) | 3–4/нед | 4–6/нед | 3–5/нед |
| Поддержание | 2–3/нед | 3–4/нед | 2–3/нед |

### 9.2 A/B тестирование гипотез

Тестировать по одному параметру за раз:

1. **Хук:** 2 варианта хука на одну тему → какой Hook Score выше
2. **Формат:** список vs сторителлинг на одну тему → какая retention
3. **CTA:** подписка vs сохранение vs коммент → какая метрика выше
4. **Длина:** 15 сек vs 30 сек на один сценарий → какой completion rate

### 9.3 Метрики для замера

| Метрика | Что показывает | Целевое значение |
|---------|---------------|-------------------|
| Watch-through rate | % досмотревших до конца | > 30% для 30 сек |
| Average view duration | Средняя длительность просмотра | > 70% длины ролика |
| Engagement rate | (Likes+Comments+Saves+Shares)/Impressions | > 5% |
| Share rate | Шеры / Показы | > 2% |
| Saves-to-views ratio | Сохранения / Просмотры | > 5% |
| Conversion rate | Переходы по ссылке / Просмотры | зависит от ниши |

## 10. ИТОГОВАЯ ФОРМУЛА ВИРУСНОСТИ

```
Вирусность = КАЧЕСТВО_СЦЕНАРИЯ × АЛГОРИТМИЧЕСКАЯ_ПОДГОНКА × ЧАСТОТА

Где:
  КАЧЕСТВО_СЦЕНАРИЯ = Hook Score ≥ 7.0 × Retention Engineering × CTA Quality
  АЛГОРИТМИЧЕСКАЯ_ПОДГОНКА = Platform Fit × Signal Optimization
  ЧАСТОТА = Posts/Week (минимальный порог: 3/нед)
```

Качество сценария определяет ~60% успеха рилса. Монтаж и визуал — остальные 40%. Но без структуры визуал бесполезен.
