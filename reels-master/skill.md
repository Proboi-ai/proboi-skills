# ReelsMaster — Система создания вирусных рилс

## Описание
Генерирует сценарии для рилсов/шортс/tiktok по полному циклу VRF (Viral Reel Framework) — от выбора хука до финального CTA. Учитывает алгоритмы платформ 2026, психологические триггеры, форматы подачи, метрики удержания и A/B тестирование.

## Как использовать

Просто опиши тему, цель и платформу. Например:

- «Нужен рилс про Proboi, цель — подписки, 15 сек, Instagram»
- «Сделай сценарий для рилса про экономию времени, охваты, 30 сек, TikTok»
- «Рилс про нейросети, цель — продажи курса, 60 сек, YouTube Shorts»

Скилл вернёт готовый сценарий с полным досье: постановка хука, психологические триггеры, приёмы retention, разметка по кадрам, словник, тайминг.

## СИСТЕМА VRF (Viral Reel Framework)

### Трёхблочная структура

```
БЛОК 1: ХУК (0–3 сек) — Остановить скролл, разрыв ожидания
БЛОК 2: ЦЕННОСТЬ (3–12/20 сек) — Выполнить обещание хука
БЛОК 3: CTA (последние 3–5 сек) — Направить энергию
```

### Нормативы слов

| Длина | Всего слов | Хук (0–3с) | Core (3–12/20с) | CTA |
|-------|-----------|------------|-----------------|-----|
| 15 сек | 40–50 | 9–12 | 22–30 | 9–12 |
| 30 сек | 80–100 | 9–12 | 55–75 | 12–15 |
| 45 сек | 120–140 | 9–12 | 95–115 | 12–15 |
| 60 сек | 160–180 | 9–12 | 130–150 | 15–20 |

### Тест качества хука (Hook Score)
Оценка по шкале 1–10 по трём параметрам:

```
Hook Score = (Curiosity × 0.35 + Specificity × 0.25 + Relatability × 0.40) × Pacing
```
Проходной балл: **≥ 7.0**

## ПСИХОЛОГИЧЕСКИЕ ТРИГГЕРЫ (7 рычагов)

Боль → Жадность → Любопытство → Эксклюзив → Социальное доказательство → Авторитет → Дефицит

**Правило:** 2–3 триггера на рилс в последовательности: боль → жадность → дефицит.

---

## АЛГОРИТМ ЗА 12 МИНУТ

1. **Цель** (30 сек) — выбрать одну метрику
2. **Формат** (1 мин) — выбрать формат подачи
3. **Хук** (3 мин) — 5–10 вариантов, выбрать по Hook Score ≥ 7.0
4. **Боль/проблема** (2 мин) — усилить, привязать к триггеру
5. **Решение/ценность** (3 мин) — выполнить обещание хука
6. **CTA** (1 мин) — под цель и платформу
7. **Тайминг** (1 мин) — прочитать вслух, подрезать
8. **Адаптация** (30 сек) — проверить по плейбуку платформы

## ПРАВИЛО КАЧЕСТВА

Качество сценария определяет **60% успеха** рилса. Монтаж и визуал — остальные 40%. Без структуры они бесполезны.

### Формула вирусности
```
Вирусность = КАЧЕСТВО_СЦЕНАРИЯ × АЛГОРИТМИЧЕСКАЯ_ПОДГОНКА × ЧАСТОТА
```
Минимальный порог частоты: **3 публикации в неделю**.
